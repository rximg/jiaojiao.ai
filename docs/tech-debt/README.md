# 技术债（Tech Debt）

本目录存放**已知待重构 / 待偿还**的技术议题：背景、现状、目标形态与关联代码，便于排期与交接。

- **命名**：建议 `YYYY-MM-DD-<主题>.md`，与仓库其他文档习惯一致。
